FXPrimus Website Design & Development

A conceptual multi-page website designed and built for forex broker FXPrimus as a university capstone project.

The goal was to produce a professional, responsive website that reflects FXPrimus's brand while showcasing modern UI/UX principles and interactive front-end development. The project went from initial Figma wireframes and colour exploration through to a fully coded, responsive site using HTML, CSS and vanilla JavaScript.
